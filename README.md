# 社区级虚假信息检测

本项目实现了一个**社区级虚假信息检测实验框架**：将检测视角从微观的节点级提升至中观的社区级，采用**两阶段策略**（规则预过滤 + 逻辑回归）进行判别，并在模拟动态网络上完成端到端评估。

> ⚠️ **先读这一条**：本项目使用 **ER 随机图模拟数据**（见 `src/utils.py`），其中「社区」是从节点集合中**随机划分**得到的、并非任何社区发现算法的输出；虚假用户标签与图结构**相互独立生成**。因此该数据集客观上不承载可判别信号，检测指标低于随机基线——这是数据设定的必然结果，详见文末「局限」一节。

## 🚀 快速开始

### 1. 环境配置

请确保已安装 Python 3.8+。

```bash
# 创建虚拟环境（可选但推荐）
python -m venv venv
# 激活虚拟环境
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

### 2. 运行实验

执行主脚本以运行完整流程（数据生成 -> 特征提取 -> 两阶段检测 -> 评估）：

```bash
python main.py
```

脚本将执行以下操作：

1. 生成模拟动态网络数据（10 个快照 × 200 个节点，随机种子固定为 42，结果可复现）。
2. 提取 8 个核心社区特征（含形成速度与成员稳定性）。
3. 应用两阶段检测策略并融合结果。
4. 执行后验验证。
5. 在控制台输出评估指标（Accuracy、Precision、Recall、F1、AUC-ROC）。
6. 写出 `data/` 下的三个数据文件。

### 3. 生成可视化图表

```bash
python src/visualization.py
```

生成三张图（**全部由上述数据文件绘制，不含任何硬编码或示意数据**）：

- `roc_comparison.png` —— 测试集上的真实 ROC 曲线
- `feature_importance.png` —— 分类器**实际学到的**标准化系数
- `community_evolution.png` —— 社区规模与内部密度随快照的真实演化轨迹

> 绘图前需先运行 `python main.py`；缺少数据文件时脚本会直接报错而非静默出图。

## 🧠 方法论

### 核心特征

模型使用 8 个特征，兼顾结构与时间演化：

- **动态特征**：形成速度 (Formation Speed)、成员稳定性 (Member Stability)
- **结构特征**：内部密度 (Internal Density)、隔离度 (Isolation Degree)、平均内部度 (Avg Internal Degree)
- **统计特征**：社区规模 (Community Size)、权重和 (Weight Sum)、权重方差 (Weight Variance)

> 注：模拟网络为无权图，`internal_edge_weight_var` 在该数据上恒为 0；且由于社区成员每个快照完全重抽，`formation_speed` 与 `member_stability` 在此数据上不具有演化含义。

### 两阶段策略

1. **第一阶段（基于规则）**：使用硬性阈值（内部密度 > 0.7、形成速度 ≤ 2、隔离度 < 0.3）预筛选高风险社区，三项中满足两项即命中。
2. **第二阶段（基于模型）**：使用带 5 折交叉验证的逻辑回归（`LogisticRegressionCV`，`class_weight='balanced'`）进行精细分类。
3. **融合逻辑**：规则命中的结果优先级高于模型判定。

> 实测：规则阶段的阈值是针对**真实网络的社区结构**设定的（真实社区内部密度通常在 0.3 以上），而本项目的模拟社区是随机划分、内部密度仅约 0.05，因此规则阶段基本不会触发——两阶段在本数据上退化为纯逻辑回归。这从另一侧面说明该模拟数据不可用于检验本框架。

### 后验验证

对判定为虚假的社区，取其在子图中连接强度前 10% 的核心节点，检查核心节点的虚假标签占比：超过 0.5 记为 `Reinforced Fake`，否则记为 `Uncertain`。该步骤用于给人可读的置信标注。

## 📊 评估指标

**虚假检测层面**：Accuracy、Precision、Recall、F1-Score、AUC-ROC，由 `src/evaluation.py` 计算并打印。

> 本项目**不产出**社区发现层面的 Modularity / NMI / 时间平滑度——这些指标属于动态社区发现算法的评价范畴，需要真实的演化网络与社区发现算法输出，本框架未涉及。

## ⚠️ 局限

1. **数据为模拟生成**：ER 随机图（度分布为泊松，无真实社交网络的重尾/无标度特性），缺少 hub 节点，而虚假信息传播的关键机制恰是「少量大 V + 大量水军」的二部结构。
2. **「社区」为随机划分**：`src/utils.py` 用 `random.randint` 将节点随机分组，未运行任何社区发现算法，因此网络中没有可被发现的结构。
3. **快照之间无时间耦合**：每个快照独立重新生成，而动态社区发现的前提是快照间存在演化依赖——本数据的「动态」不成立。
4. **标签与结构无关**：虚假用户标签与图结构独立生成，客观上不存在可学信号，分类器 AUC 低于随机基线。**该结果反映的是数据设定的缺陷，而非方法本身的效果。**
5. **单次划分、样本量小**：测试集仅 30 个社区样本，未做分层抽样与多次重复。
